# 高码率视频推流与音画同步网络调优指南

在进行海外直播与高清视频推流时，合理的编码器与网络参数搭配是零卡顿的前提。

## OBS 核心推流参数推荐

1. **速率控制**：务必选择 **CBR (恒定码率)**。VBR (可变码率) 会在复杂动态画面时突发产生数倍带宽，容易导致网络拥堵丢包。
2. **码率设置参考**：
   - 1080P / 60FPS：建议 6,000 ~ 9,000 Kbps（需要至少 20Mbps 稳定上行）。
   - 4K / 60FPS：建议 15,000 ~ 25,000 Kbps（需要至少 60Mbps 稳定上行）。
3. **关键帧间隔 (Keyframe Interval)**：设置为 **2 秒**。各主流流媒体平台（YouTube、Twitch）要求严格的 2s 关键帧以保障画面切片同步。
4. **低延迟推流协议**：优先选择 RTMPS 或 SRT 协议，配合低丢包的 IPLC 专线，可以实现近乎实时的弹幕互动。
